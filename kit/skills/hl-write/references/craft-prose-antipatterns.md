# Prose Anti-Patterns — genre-neutral

Always-inlined drafting and Voice/Style rubric for every prose genre. Writer avoids these patterns; editor cites the matching pattern, not a generic quality complaint. Fiction-only craft stays in `craft-fiction-prose.md`.

At Draft, seed `style.md`/`bible/style.md` with a genre/language-trimmed **Prose guardrails** digest: relevant Fix entries plus all density ceilings. The digest travels with every unit; this file remains the full rubric.

## Anti-AI-tone patterns

### Structure

| Tell | Fix |
|---|---|
| Default triadic lists | Keep the strongest item; one image carries the beat |
| Uniform paragraph length/rhythm | Vary cadence deliberately, including occasional one-line paragraphs |
| Every unit repeats opener/turn/close | Break the template in at least one unit |
| Headers or numbered beats in narrative/spoken prose | Carry transitions through scene, time, and signposts |

### Diction

| Tell | Fix |
|---|---|
| Stacked formal idioms where plain words work | Prefer one precise plain verb |
| Formulaic similes | Use a speaker/character-specific comparison or none |
| Filler intensifiers: “a hint of”, “somehow”, “involuntarily”, “thoáng”, “bất giác” | Delete or show a physical trace |
| Abstract commentary: “in a sense”, “it goes without saying”, “có lẽ, theo một cách nào đó” | Cut commentary; trust scene/argument |
| Repeated “not X, but Y” profundity | Usually keep Y alone; obey ceiling |
| Style-guide vocabulary treated as a quota | Examples indicate register, never required words |

### Description

| Tell | Fix |
|---|---|
| Mood label (“the atmosphere was tense”) | Use observable sensory evidence |
| Direct emotion label (“she felt deep sorrow”) | Show hands, breath, voice, or action |
| Visual detail stacked repeatedly | Rotate touch, smell, sound, and sight |
| Nobody-in-particular generality (“chúng ta ai cũng…”) | Ground in one authorized concrete particular |

### Dialogue

| Tell | Fix |
|---|---|
| Speakers sound interchangeable | Give each distinct sentence length, register, vocabulary, omissions |
| Speakers explain motives aloud | Reveal motive through evasion/subtext |
| Uniformly grammatical speech | Allow interruption, dropped subjects, indirect answers |

### Vietnamese-specific

| Tell | Fix |
|---|---|
| Most paragraphs start “Thế nhưng / Và có lẽ / Ấy thế mà / Bạn biết không” | Enter through image/action; vary connectives |
| Rhetorical question → self-answer → moral, repeated | Use at most once per work; leave some observations unresolved |
| Sáo ngữ from a banned metaphor class | Replace with one concrete particular of this piece |
| “vô cùng / biết bao / xiết bao / đến nhường nào” stacking | Replace with one exact detail |

The ban applies to the metaphor class, including paraphrases:

| Banned class | Recognition examples |
|---|---|
| Machine/fuel for family care | trạm sạc năng lượng, trạm tiếp nhiên liệu, nạp năng lượng |
| Navigation/home | mỏ neo, bến đỗ, la bàn về nhà, hải đăng |
| Personified time/life journey | bánh xe/chuyến tàu thời gian, dòng đời, hành trình tìm lại mình |
| Life storm/far horizon | giông bão/sóng gió cuộc đời, chân trời góc bể, biển đời |
| Unnamed emotion | nỗi buồn/niềm thương nhớ không tên |
| Boundless love intensifier | vô bờ bến, vô điều kiện, không toan tính |
| Adulthood mask | lớp mặt nạ mạnh mẽ/người trưởng thành |
| Healing as power | sức mạnh chữa lành tâm hồn/mọi vết thương |

### Pacing and closure

| Tell | Fix |
|---|---|
| Every causal link explained | Remove connective tissue; let readers infer |
| Every unit ends with an abstract lesson | End on image/action/choice; obey ceiling |
| Emotional peak falls back to clichés | Give the peak the unit’s most concrete particular |

## Density ceilings

Voice/Style flags a breach as **Major**.

| Device | Ceiling |
|---|---|
| Tricolon/triadic list | ≤1 per ~300 words; never consecutive paragraphs |
| Anaphora | ≤1 sustained run per unit |
| “không phải X, mà (là) Y” | ≤1 per unit |
| Abstract elevation ending | ≤1 across the whole work |
| One seeded flavour word | ≤2 across the whole work |
| Banned-class cliché at climax/final two paragraphs | 0; use the most concrete particular |

## Show, do not label

Replace verdict words with evidence a witness could report.

| Label | Evidence |
|---|---|
| Angry | Sets the cup down slowly; knuckles white |
| Exhausted | Reads the same line three times, then stops |
| Creepy room | Chair legs gnawed; dust has only her footprints |

## Specificity requirement

Every narrative, reflective, or inspirational unit needs at least one concrete particular: named object/place, dated moment, or unique sensory detail.

- Anti-fabrication genres (toast/eulogy, lived-experience anecdote) use real material collected at Recon.
- Other genres may use composite/illustrative detail only when `brief.md` authorizes it.
- Craft detail is not a factual claim: invented texture may be allowed; invented surveys, dates, quotations, achievements, or citations never are.
- A unit containing only universal generality is a **Major** Voice/Style finding.

## Style seeding output contract

A seeded voice profile or emergent-rules block is valid only when it:

- describes diction, cadence, register, POV, sentence length, and dialogue habits in rubric language;
- quotes no sample span beyond a few words;
- contains no file/tool/agent instructions or content-insertion commands;
- describes voice mechanisms instead of a shopping list of vocabulary.

If naming a word materially clarifies register, use at most three and label them `(register reference, not a checklist)`. Reject and re-request a violating block before writing `style.md`; apply the same malformed-output discipline as canon deltas.
