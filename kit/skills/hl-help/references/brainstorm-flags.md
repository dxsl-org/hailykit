# `{skill:hl-brainstorm}` Persona Flags

One persona flag answers through a specific lens instead of running the full brainstorm cycle first.

| Flag | Vantage | Scope range |
|---|---|---|
| `--architect` | System structure and evolvability | System -> Component |
| `--scientist` | Empirical validation and measurement | Cross-level |
| `--social-scientist` | Human and organizational behavior | Individual -> Societal |
| `--philosopher` | Logic and systems thinking | Meta |
| `--economist` | Incentives and resource allocation | Micro -> Macro |
| `--strategist` | Long-term positioning | Product -> Business |
| `--creative-director` | Creative vision and experience integrity | Concept -> UX detail |
| `--manager` | Organizational capacity and operations | Decision -> Operations detail |
| `--devil` | Adversarial challenge to the premise | Everything |

`--deep` remains an alias for `--debate --edges`.

Examples:

```text
{skill:hl-brainstorm} --architect "how should we structure auth?"
{skill:hl-brainstorm} --strategist "should we build or buy?"
{skill:hl-brainstorm} --devil "is our approach fundamentally wrong?"
{skill:hl-brainstorm} --debate "add real-time notifications"
{skill:hl-brainstorm} --edges "checkout flow"
```
