# Canvas Design System

Canvas work is visual-first communication: form, space, rhythm, and color carry the message; text stays sparse and structural.

## Core Philosophy

- Visual communication comes first.
- Text is minimal, intentional, and part of the composition rather than a paragraph layer.
- Use spatial relationships, color fields, geometry, texture, and scale to explain the idea.
- Build a coherent system, not a one-off collage.

## Required Philosophy Artifact

Every canvas delivery includes `philosophy.md` with:

- movement or direction name
- space and form principles
- color and material approach
- scale and rhythm guidance
- composition and hierarchy rules
- execution notes for follow-on pages or variants

Keep the philosophy concise but specific enough to guide later refinement.

## Visual Rules

- Keep the composition at roughly `90%` visual communication and no more than `10%` text.
- Limit the palette to `2-5` colors.
- Use deliberate repetition, geometry, or structural motifs to create rhythm.
- Typography should behave like a graphic element, usually labels or short anchor phrases.
- Prefer clean boundaries, clear margins, and contained layering over decorative sprawl.

## Boundaries And Output

- Nothing should fall off the page accidentally.
- Avoid overlaps that reduce clarity unless overlap is an explicit compositional choice.
- Keep margins clean and intentional.
- Default to a single page unless the brief asks for a series.
- Required output files: `philosophy.md` plus the visual export as `.pdf` or `.png`.

## Multi-Page Systems

When the brief asks for multiple pages:

- Treat page one as the reference system.
- Keep palette, typography logic, and compositional grammar consistent across pages.
- Vary focal points and spatial arrangements without breaking the shared philosophy.
- Ensure each page can stand alone while still reading as part of one family.

## Refinement Loop

1. Create the first composition from the approved philosophy.
2. Refine the existing elements before adding more.
3. Tighten spacing, alignment, edge relationships, and contrast.
4. Re-check that the page still honors the visual-first and minimal-text contract.
5. For multi-page work, verify consistency across the full set after each refinement pass.

## Useful Direction Families

Use these as starting philosophies, not rigid templates:

| Direction | Emphasis |
|---|---|
| Concrete Poetry | bold geometry and monumental type moments |
| Chromatic Language | color as the main information system |
| Analog Meditation | quiet texture, negative space, restrained type |
| Organic Systems | clustered natural forms and modular growth |
| Geometric Silence | order, restraint, and grid precision |

## Quality Checks

- visual-first message still reads without long explanatory text
- palette remains within the `2-5` color boundary
- text is short, intentional, and integrated
- edges, margins, and containment are clean
- multi-page sets stay consistent without becoming repetitive

## Use Cases

Apply this system to:

- brand identity explorations
- poster systems
- visual manifestos
- editorial compositions
- exhibition or presentation inserts
- design system concept pages
- art-led documentation covers
